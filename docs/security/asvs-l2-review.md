# Security review against OWASP ASVS level 2 (Sprint 9a)

**Scope and limits.** An in-house review by the development team, area by area against ASVS 4.0 level 2, with evidence in the code and tests. It **supports, and does not replace,** the independent penetration test (Sprint 9c). Status: ✅ in place · ⚠️ open (owner and plan) · ➖ accepted with reason.
