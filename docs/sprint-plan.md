# Sprint plan

Two-week sprints. Phase 1: 10 sprints (~20 weeks) with a dedicated team of ~5; ~12 sprints if shared with the ERP team.

## Phase 1

| Sprint | Focus                                | Main output                                                                                                 | Client gate                      |
| ------ | ------------------------------------ | ----------------------------------------------------------------------------------------------------------- | -------------------------------- |
| 0      | Brand and kickoff                    | Logo, brand guideline, tokens, project docs, client checklist                                               | Approve brand                    |
| 1      | UI/UX design                         | Three homepage concepts, design system, key screens                                                         | Approve design                   |
| 2      | Foundation                           | Repo scaffold, Docker, CI, auth + 2FA, roles, settings, audit log, feature flags                            |                                  |
| 3      | Listings and CMS                     | Categories, document types, listing workflow, pages, blog, gallery, menus, Sell with us form                |                                  |
| 4      | Buyers and KYC                       | Registration, automated ID verification, KYC queue, buyer dashboard, bank verification                      |                                  |
| 5      | Payments                             | Gateways, deposits, invoices, refund queue, reconciliation                                                  | Legal docs + trust account ready |
| 6      | Bidding engine                       | Live bidding, proxy bids, soft close, shill protection, WhatsApp alerts, control room                       |                                  |
| 7      | Settlement, events, premium          | Winner/runner-up/default, payouts, transfer tracker, events + QR, premium slots                             |                                  |
| 8      | Seller module (off), SEO/AEO, growth | Packages, add-ons, structured data, city/category pages, share cards, PDF brochures, analytics, legal pages |                                  |
| 9      | Testing and launch                   | Security + load tests, UAT, content loading, go-live                                                        | Approve go-live                  |
