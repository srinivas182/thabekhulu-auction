# ADR 0006 — Theme manager (Sprint 2c-2)

**Status:** Accepted

| Decision                                                                                                                                                                                                                       | Rationale                                                         | Alternative considered           |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------- | -------------------------------- |
| Two independent themes, `website` and `admin`, each with light and dark palettes of 8 colours, a font pairing, a corner style and logos                                                                                        | Spec 7; the back office and public site have different needs      | One shared theme                 |
| Published theme compiled to CSS custom properties, cached forever, inlined in the page head with the CSP nonce; cleared on publish                                                                                             | No extra request, no flash of brand colours, no rebuild or deploy | Generated CSS file per publish   |
| Only validated values reach the CSS: 6-digit hex colours and whitelisted font/corner keys; unknown keys (e.g. status colours) are dropped                                                                                      | Inlined CSS must not be injectable                                | Free-text CSS values             |
| WCAG 2.2 AA checks on every save and publish: 4.5:1 text, 3:1 buttons and focus rings, plus the fixed status colours against the chosen backgrounds (36 checks). Failing pairs show the nearest passing colour of the same hue | Spec 7.2; an admin can't publish an unreadable site               | Warning only                     |
| Contrast maths in PHP (authoritative) mirrored in TypeScript for instant feedback                                                                                                                                              | Immediate feedback without trusting the browser                   | Server round-trip on each change |
| Draft → publish; restore and reset publish immediately (with confirmation) and archive the previous version                                                                                                                    | One-click restore as specified; history is never lost             | Restore into a draft             |
| Eight curated pairings, each a separate Vite entry; only the published pairing's fonts load (the theme page loads all for previews)                                                                                            | Choice without slowing every page                                 | Load all fonts everywhere        |
| Back office changes only its interface font; headings keep the brand display face                                                                                                                                              | Spec 7.1                                                          | Full pairing for the back office |
| SVG logos sanitised with enshrined/svg-sanitize (scripts, event handlers, remote references removed); favicons resized to 32 px and 180 px with GD; SVG favicons kept as SVG                                                   | Spec 7.2; uploaded SVG is a script-injection risk                 | Reject SVG                       |
| Fixed status colours darkened to pass AA on the brand backgrounds: Live #2d7b4e, Closing soon #946219, Coming soon #656e6a (light mode)                                                                                        | The Sprint 0 values failed 4.5:1 (3.26 and 4.28)                  | Keep original values             |
