# ADR 0005 — Settings, audit log and feature flags (Sprint 2c-1)

**Status:** Accepted

| Decision                                                                                                                                                                              | Rationale                                                                            | Alternative considered           |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ | -------------------------------- |
| Typed settings with spatie/laravel-settings (General, Auction, Security), cached; defaults in `database/settings`                                                                     | Typed values, versioned defaults, one cache refresh on save                          | Key-value table read ad hoc      |
| A `SettingsRegistry` describes every field (type, label, rules, read-only); one controller and one page render all groups                                                             | Later sprints add a group by adding a registry entry                                 | A controller and page per group  |
| Read-only fields (currency, staff 2FA) are skipped server-side whatever the request contains                                                                                          | The UI disabling a field is not a control                                            | Rely on disabled inputs          |
| IP allow-list must include the saving admin's own address                                                                                                                             | Prevents an admin locking everyone out                                               | Warning only                     |
| Session lifetime applied by middleware before the session starts                                                                                                                      | Takes effect without a deploy                                                        | Config only                      |
| Notification, Payment, KYC and SEO settings groups are created in their own sprints (4, 5, 8)                                                                                         | Avoids empty placeholder screens                                                     | Stub groups now (spec 6)         |
| Audit log on spatie/laravel-activitylog with a custom `AuditEntry` model: IP and user agent columns; secrets removed and mobile numbers masked before saving; update and delete throw | Spec 8; immutability enforced in the model, not just by hiding buttons               | Separate audit table and package |
| Auth and staff events are logged by one subscriber; users log their own field changes; roles, settings and flags log explicitly with before/after                                     | Each change recorded once, at the place that knows its meaning                       | Database triggers                |
| Retention 7 years, pruned daily by `activitylog:clean` (bulk delete, bypasses model guards by design)                                                                                 | Spec 8                                                                               | Manual archiving                 |
| Feature flags with Laravel Pennant, stored against the global (null) scope                                                                                                            | Platform-wide switches; Pennant gives caching and a database store                   | Per-user flags; config values    |
| Search engine indexing moved from config to the `public_site_indexing` flag (defaults to `PUBLIC_SITE_INDEXING` until first changed)                                                  | Can be switched on at launch from the back office                                    | Redeploy with a new env value    |
| `soft_close` is a setting, not a flag                                                                                                                                                 | It is a per-auction business rule with related numbers, not a feature release switch | Separate flag (spec 9 table)     |
