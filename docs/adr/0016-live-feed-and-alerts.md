# ADR 0016 — Live feed and alerts (Sprint 6b)

**Status:** Accepted

| Decision                                                                                                                                                                                                                                                                                                 | Rationale                                                                                                            | Alternative considered       |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- | ---------------------------- |
| Laravel Reverb (first-party WebSocket server) as its own container; nginx proxies `/app` and `/apps` on the same domain                                                                                                                                                                                  | Same-origin WebSockets; no third-party service; fits the Docker setup (ADR 0003 deferred Reverb to Sprint 6)         | Pusher / Ably                |
| `AuctionUpdated` broadcasts the **whole public view** (current, next, end time, extensions, bidder-number feed, leader's bidder number) on `listing.{ulid}`, after the transaction commits (`ShouldDispatchAfterCommit`)                                                                                 | Browsers update in place: 2 000 viewers don't all re-fetch the page on every bid; nobody sees a bid that rolled back | Event as a "reload" signal   |
| Each browser works out "you're leading" from the leader's bidder number; names and maximums never leave the server (tested)                                                                                                                                                                              | Public payload stays anonymous (B7)                                                                                  | Per-user events for everyone |
| `useLiveAuction` touches Echo only inside a browser effect; if the WebSocket isn't connected it refreshes every 5 seconds                                                                                                                                                                                | Server rendering never loads pusher-js; the page always stays current                                                | WebSockets only              |
| CSP `connect-src` lists the Reverb origin explicitly (`wss://<host>`)                                                                                                                                                                                                                                    | Not every browser treats `'self'` as covering WebSockets                                                             | Rely on `'self'`             |
| Private `bidder.{id}` channel for outbid alerts, authorised for its owner only (tested with the Reverb driver); Echo sends the XSRF cookie                                                                                                                                                               | Personal alerts stay private                                                                                         | Public alerts                |
| Outbid notice to the previous leader only when the lead changes; browser alert always, email and WhatsApp at most once per 10 minutes per listing                                                                                                                                                        | No flood during a bidding war                                                                                        | Every outbid                 |
| Closing-soon alerts at 60 and 10 minutes (scheduler, every minute), recorded in `auction_alerts` so each is sent once even when soft close moves the end                                                                                                                                                 | Exactly-once alerts                                                                                                  | —                            |
| WhatsApp via Meta's WhatsApp Business Cloud API: **template messages only**, to buyers who **opted in** (recorded with time; POPIA consent text; opt out any time); token encrypted and write-only; failures logged, email always sent                                                                   | Lawful, reliable alerts                                                                                              | SMS                          |
| Phone numbers are normalised (spaces, brackets, dashes) before validation (found in testing: typed numbers were rejected)                                                                                                                                                                                | People type numbers with spaces                                                                                      | Strict input                 |
| Verified with a real Reverb server: a bid committed on the server appeared on a guest's page 0.02 s later, without a reload, with no CSP errors                                                                                                                                                          | —                                                                                                                    | —                            |
| Private alert channels are keyed by the user's **ulid** (`bidder.{ulid}`): the browser never receives internal numeric ids, so a channel keyed by id could never be subscribed (found when CI's TypeScript check failed; verified afterwards in a real browser: channel authorised, outbid banner shown) | Private alerts actually reach the browser                                                                            | Expose numeric ids           |
| The suggested bid follows the live minimum until the bidder types their own amount (found in the browser check: the box kept a stale amount that would be refused)                                                                                                                                       | The quickest action is always a valid bid                                                                            | Static default               |
