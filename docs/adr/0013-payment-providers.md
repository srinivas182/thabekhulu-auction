# ADR 0013 — Payment providers and escrow (Sprint 5b)

**Status:** Accepted

| Decision                                                                                                                                                                                                                                                                                                                                                                                                                                  | Rationale                                                       | Alternative considered    |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- | ------------------------- |
| Pluggable payment providers (same pattern as verification, ADR 0010): TradeSafe for deposit escrow, Paystack for small card payments, Ozow registered but **not ready**; trust-account EFT always available (P1)                                                                                                                                                                                                                          | Thabekhulu chooses by contract; EFT never depends on a provider | Hard-wired gateway        |
| Super admin chooses how deposits can be paid: EFT only, or EFT plus an enabled escrow provider                                                                                                                                                                                                                                                                                                                                            | Clear, reversible switch                                        | Per-listing provider      |
| TradeSafe: OAuth client credentials (`auth.tradesafe.co.za`), GraphQL; one transaction per deposit with **our deposit reference as theirs**; **Thabekhulu's own TradeSafe token as the receiving party**, so escrowed money stays with TradeSafe until our rules refund or apply it; checkout limited to EFT and Ozow (card caps at R25 000; EFT has no limit, Ozow up to R2m); the 15-minute link is generated on click and never stored | Large deposits held by an independent escrow agent              | Seller as receiving party |
| TradeSafe callbacks are **not signed**, so a callback is processed only if (1) the secret in its URL matches, (2) it comes from TradeSafe's published IPs for the mode, and (3) TradeSafe's API itself reports `FUNDS_RECEIVED` for that transaction; the amount is taken from the API, never the callback body; the transaction id must match the deposit                                                                                | A forged callback cannot create money in the ledger             | Trust the callback        |
| Paystack: webhook `x-paystack-signature` = HMAC-SHA512(body, secret) **and** `transaction/verify` must report success in ZAR before money is recorded                                                                                                                                                                                                                                                                                     | Defence in depth                                                | Signature only            |
| Every provider event is processed once (unique provider + event id); provider money goes through the same `DepositService` as EFT (ledger, receipt, account lock)                                                                                                                                                                                                                                                                         | One money path                                                  | Separate flows            |
| Provider failure shows an error and keeps EFT available                                                                                                                                                                                                                                                                                                                                                                                   | Bidders can always pay                                          | Block payment             |
| Ozow's hash field order must be confirmed against sandbox credentials, so the adapter can't be enabled yet; escrowed deposits can already be paid by Ozow inside TradeSafe                                                                                                                                                                                                                                                                | No integration that only looks finished                         | Guess the order           |
| TradeSafe's token-creation input and live GraphQL address are marked "confirm in sandbox"; the address is configurable                                                                                                                                                                                                                                                                                                                    | Honest about what docs didn't show                              | Hard-code                 |
| Laravel passes unmatched route segments to the first scalar parameter, so the TradeSafe callback has its own controller method taking `$secret` (found in testing: all callbacks were 404)                                                                                                                                                                                                                                                | Correct routing                                                 | —                         |
