# ADR 0027 — Demo content for demonstrations and UAT

**Status:** Accepted

| Decision                                                                                                                                                                                                                                                                                                                   | Rationale                                                                 | Alternative considered   |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- | ------------------------ |
| `DemoSeeder` adds 7 sample listings across the four categories (live open auctions, a live sealed tender, coming-soon listings including a Thabekhulu-renovated home), a sample event and two sample articles; every title ends "(sample)", every slug starts `sample-`; never part of `DatabaseSeeder`; safe to run twice | Prospects see a complete site; nothing can be mistaken for a real listing | Hand-entered listings    |
| Photos: branded generated images by default; real photos only from **Pexels** (free licence) via `demo:photos`, which accepts only pexels.com links and downloads on the server; a failed download keeps the existing photo. Images found through general web search are not used: their licences are unknown              | Lawful images on a public domain                                          | Images from a web search |
| No "sold" sample: a sold result shows the winner's bidder number, and inventing a bidder risks breaking that page                                                                                                                                                                                                          | —                                                                         | Fake bidder              |
| `demo:remove` deletes all sample content before launch, audited; a sample with real activity (bids, deposits, tickets) is kept for a person to decide                                                                                                                                                                      | No accidental loss of test transactions                                   | Blind delete             |
