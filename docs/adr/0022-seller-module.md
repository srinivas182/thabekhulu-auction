# ADR 0022 — Seller module, switched off (Sprint 8a)

**Status:** Accepted

| Decision                                                                                                                                                                                                                                                                      | Rationale                                | Alternative considered |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- | ---------------------- |
| Uses the existing `sellers` feature flag (Sprint 2, off, Phase 2) rather than a new `seller_module` flag named in the spec; a new `feature:<flag>` route middleware answers **404** while a flag is off, so seller pages don't exist in Phase 1 (T1)                          | One flag, no half-visible feature        | New flag               |
| Seller accounts use the existing Seller user type and role; registration records POPIA consent; sellers use the Sprint 4 identity verification (T2)                                                                                                                           | Reuse, not duplication                   | Separate flow          |
| **One account per ID number across buyers and sellers** (verification's unique ID hash): a seller can't also hold a buyer account with the same ID, closing the "seller bids on own property" gap noted in Sprint 6a (tested)                                                 | Shill protection without new rules       | Extra checks           |
| Seller submissions become leads (Sprint 3c) with encrypted documents (title deed, mining right, authority to sell); staff convert a lead into a draft listing (category + title, category defaults) linked to the seller; one conversion per lead; sellers never publish (T3) | Staff stay in control of every listing   | Self-publish           |
| Lead conversion and lead documents work with the flag off too: "Sell with us" leads from the public site benefit now                                                                                                                                                          | Useful in Phase 1                        | Flag-gated             |
| Seller packages (name, price, days, listing allowance) defined by staff and assigned to sellers; **approving an auction that would end after the seller's package expiry, or with no package, is a readiness problem** (PRD rule); online package purchase is Phase 2         | PRD rule enforced where approvals happen | Checked at payment     |
| Seller dashboard shows verification, package expiry, submissions, and listings with bid count, result and payout status; seller identity stays off the public site                                                                                                            | —                                        | —                      |
| The seller packages admin page has no navigation entry while the flag is off; add one at Phase 2 go-live                                                                                                                                                                      | Nothing points at a 404                  | —                      |
