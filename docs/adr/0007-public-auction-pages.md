# ADR 0007 — Public auction pages (Sprint 3b-2)

**Status:** Accepted

| Decision                                                                                                                                                                                                                                             | Rationale                                                                                                                                                 | Alternative considered                                  |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| Public data only through `PublicListing` (explicit allow-list); seller terms, fee, street address, review notes and internal documents never leave the server; a test plants unique values and asserts they appear nowhere in HTML, props or sitemap | One choke point is auditable; a leak would expose seller economics                                                                                        | Hiding fields in each page                              |
| Map positions rounded to 2 decimals (~1 km)                                                                                                                                                                                                          | Exact sites stay private; the page shows "approximate area"                                                                                               | Exact pins                                              |
| Search with indexed database queries behind `ListingSearch` instead of Meilisearch for now (changes D5)                                                                                                                                              | Meilisearch cannot run in CI or the dev sandbox, so search would be untestable; SQL is fast well beyond launch volumes; switching later touches one class | Meilisearch now                                         |
| Structured data (`RealEstateListing`, `Offer`, `BreadcrumbList`) written by the Blade template with the CSP nonce                                                                                                                                    | Always in the HTML even if the server-side render service is down                                                                                         | React `<Head>` (only present with SSR)                  |
| Browser-only output (maps, live countdowns) waits for `useMounted`; dates pre-formatted in SAST on the server                                                                                                                                        | Server and first client render must match (React hydration error #418 found during review)                                                                | `typeof window` checks; formatting dates in the browser |
| Wrong city segment in a listing URL 301-redirects to the canonical URL                                                                                                                                                                               | One URL per listing for search engines                                                                                                                    | 404                                                     |
| CSP allows OpenStreetMap tiles (`img-src`) and privacy-enhanced YouTube/Vimeo (`frame-src`) only                                                                                                                                                     | Spec D2, D3                                                                                                                                               | Wider allow-lists                                       |
| Vite+ security update (dev tooling only) deferred to after 30 October 2026                                                                                                                                                                           | 1.3.0 was published 16 October; releases are adopted after two weeks; major version jump with dependency conflicts                                        | Upgrade immediately                                     |
