# ADR 0008 — Website content (Sprint 3c-1)

**Status:** Accepted

| Decision                                                                                                                                                                                                                                                                | Rationale                                                                                          | Alternative considered                           |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| Pages are an ordered list of typed blocks (text, two columns, call to action, questions) stored as JSON; every block validated and its HTML cleaned on save                                                                                                             | Editors build pages without HTML; nothing unsafe reaches the public site                           | Free-form HTML pages                             |
| Image blocks come with the media work in 3c-2 (gallery)                                                                                                                                                                                                                 | Avoids a second upload system                                                                      | Image block now (spec 6 listed five block types) |
| Content pages live at the top level (/about, /privacy) via a catch-all registered last; platform words are reserved and rejected on save                                                                                                                                | Short, memorable URLs without shadowing application routes                                         | /pages/{slug}                                    |
| Ten standard pages seeded (about, how it works, buyer's guide, fees, contact, Rules of Auction, privacy, PAIA manual, disclaimer, automatically available records), marked "needs content"; they can be edited or unpublished but not deleted, and keep their addresses | Legal pages must exist and stay linkable; placeholders are visible until real text arrives         | Create pages manually at launch                  |
| FAQPage structured data from question blocks, written by Blade                                                                                                                                                                                                          | Search and AI answers; independent of the render service (ADR 0007)                                | React head                                       |
| Menus and the FFC number cached as one navigation payload shared with every page, cleared on change                                                                                                                                                                     | One query-free lookup per request                                                                  | Query per request                                |
| Home page featured auction is its own setting, separate from a listing's "featured" flag (which drives the Premium chip until premium slots in Sprint 7)                                                                                                                | Hero choice and premium placement are different decisions                                          | Reuse the listing flag                           |
| Settings properties with nested arrays use the native `array` type with no `@var` docblock                                                                                                                                                                              | spatie/laravel-settings derives casts from `@var` and cannot parse array shapes (found in testing) | Typed DTO casts                                  |

## Additions in 3c-2

| Decision                                                                                                                                               | Rationale                                                                   | Alternative considered                       |
| ------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------- | -------------------------------------------- |
| "Sell with us" photos stored on the private disk; staff open them through an audited route that needs `leads.view`                                     | Photos come from the public before any vetting and may show people or homes | Public storage                               |
| Public forms protected by a hidden honeypot field (bots get a normal thank-you and nothing is stored) and a limit of 5 submissions an hour per address | Stops spam without a CAPTCHA that hurts real users                          | reCAPTCHA (third-party script, privacy cost) |
| New leads and enquiries alert the office address from General settings; replies are sent by email from the back office and stored with the enquiry     | One place to see the conversation; the audit log records every reply        | Replying from a personal mailbox             |
| Articles are visible only when published and their publish date has passed (future date = scheduled); `BlogPosting` structured data from Blade         | Scheduling without a background job; search and AI answers                  | Cron-based publishing                        |
| Image blocks may only use images uploaded to the same page, and need alt text                                                                          | Stops one page embedding another's files; accessibility                     | Free image URLs                              |
| Form "sent" states use Inertia flash data (`page.flash`), not props                                                                                    | Inertia 3 delivers flash on the page object                                 | Session props                                |
